Diagramme de classes – Cœur pédagogique EduFlex

Modèle métier et pédagogique aligné sur la structure Java du projet
User
- id: Long
- nom: String
- prenom: String
- email: String
- role: Role
- active: boolean
Course
- id: Long
- title: String
- description: String
- level: String
- price: Double
- published: boolean
- category: Category
- instructor: User
Category
- id: Long
- name: String
- description: String
- active: boolean
User → instructor / apprenant → Course
Module
- id: Long
- title: String
- description: String
- orderIndex: Integer
- course: Course
Lesson
- id: Long
- title: String
- content: String
- course: Course
- module: Module
- videoUrl: String
- documentUrl: String
- orderIndex: Integer
Progress
- id: Long
- user: User
- course: Course
- completedLessons: int
- totalLessons: int
- percentage: double
- status: ProgressStatus
Course 1 ──── N Module 1 ──── N Lesson
User 1 ──── N Enrollment N ──── 1 Course

Conventions métier

  • Un Course appartient à une Category et est dispensé par un User avec le rôle formateur.
  • Un Course contient plusieurs Module ; chaque module contient plusieurs Lesson.
  • Un User peut s’inscrire à plusieurs cours via Enrollment.
  • Un Progress suit l’avancement d’un apprenant sur un cours donné.
  • Les relations sont orientées comme dans le modèle JPA réel : compositions pédagogiques et associations entre utilisateur, cours, progression et inscription.
